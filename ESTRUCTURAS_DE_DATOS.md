# Estructuras de datos en GO

## Matrices (arrays)

Una matriz es una estructura de datos que almacena un número fijo de elementos del mismo tipo. Su tamaño debe ser definido al momento de declararlo y no puede ser modificado posteriormente o en tiempo de ejecución.

Son Tipos de valores en __GO__ por lo que al asignarlos a variables o pasarlo a funciones, se crea una copia no una referencia.

## Rebanadas (slice)

Un slice es una estructura de datos dinámica que proporciona una vista flexible derivadas de un array. A diferencia de los arrays estos pueden cambiar de tamaño
